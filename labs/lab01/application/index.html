AWS LEARNING / LAB01

WAFリクエスト実験

入力した文字列を、このページと同じAPIの GET /search へ1件送信します。
HTTP応答を確認した後、CloudWatchでWAFの一致ルールを調べます。

1. 入力して送信

このアプリは入力をSQLやHTMLとして実行せず、JSONとして返します。例文を選んだだけでは送信されません。

2. HTTP応答

まだ送信していません。

送信時刻・labcase・リクエストIDを表示します。
レスポンス本文を表示します。

HTTP 200はWAF検知の証拠ではありません。403でも、一致ルールはWAFログで確認してください。画面だけでCountやBlockの原因を断定しません。

3. WAFログを確認

東京リージョンのCloudWatch Logs Insightsで aws-waf-logs-Lab01Stack を選び、実験時刻を含む範囲を検索します。ログ反映には時間がかかる場合があります。

送信後、この実験だけを探すクエリを表示します。

@message を展開し、ruleGroupList・nonTerminatingMatchingRules・labels と最上位の action を確認します。画面の実験記録は直近20件まで、再読み込みで消えるため必要なら保存してください。WAFログはAWS側に別途保存されます。
